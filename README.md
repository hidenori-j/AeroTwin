# AeroTwin

**空間環境3Dデジタルツイン・ロボット事業**

自律移動ロボット（ROS 2 / LiDAR）とUnityの3Dシミュレーション技術を組み合わせ、目に見えない室内の空気環境（CO2滞留・温度ムラ・熱だまり）を立体的に可視化するBtoBソリューションです。

## プロジェクト概要

- **ターゲット市場**：データセンター、大規模オフィス・工場、植物工場
- **技術構成**：Raspberry Pi 5 / RPLiDAR S3 / SCD41 / ROS 2 / Unity
- **差別化**：3Dプリント製排熱隔離チャンバーによる測定精度確保 + Unity 3Dヒートマップ可視化
- **ビジネスモデル**：空間診断スポット契約（Phase 1）→ PoC機材納品（Phase 2）→ SaaS / リース（Phase 3）
